# CantonHub Landing Page

A developer onboarding portal for Canton Network - your gateway to building privacy-first, interoperable blockchain applications.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Lucide React (icons)

## Getting Started

```bash
# Install dependencies
yarn

# Start development server
yarn dev

# Build for production
yarn build

# Preview production build
yarn preview
```

## Project Structure

```
src/
├── App.jsx              # Main app wrapper
├── CantonLanding.jsx    # Landing page component
├── index.css            # Tailwind CSS imports
└── main.jsx             # React entry point
```

## Features

- Animated parallax background
- Responsive navigation
- 3-step developer roadmap (Learn → Build → Go Live)
- Canton vs EVM comparison table
- Interactive FAQ accordion
- Partner showcase
- Contact CTA section
